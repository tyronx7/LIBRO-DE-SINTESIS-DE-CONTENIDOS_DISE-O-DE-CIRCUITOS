## Cómo usar este libro
1. Empieza por el `README.md` de cada unidad y semana: contiene objetivos, mapa de contenidos y resumen.
2. Los archivos `01_Teoria_*` sintetizan la teoría; los `02_`/`03_` contienen talleres, actividades y resoluciones.
3. Las fórmulas usan notación LaTeX (`$...$`); se visualizan correctamente en VS Code, Obsidian, GitHub y Typora.

## Convenciones de notación
| Símbolo | Significado |
| :---: | :--- |
| $A'$ | Complemento (NOT) de $A$ |
| $A\cdot B$ / $AB$ | AND |
| $A+B$ | OR |
| $A\oplus B$ | XOR |
| $m_i$ / $M_i$ | Minitérmino / Maxitérmino de índice $i$ |
| $\sum m(\dots)$ / $\prod M(\dots)$ | Forma canónica SOP / POS |
| `X` / $d(\dots)$ | Condición indiferente (*don't care*) |
